# 🖥️ JRN TUI Interface & UX Specification

> **Концепт интерфейса терминального клиента JRN**, объединяющий лучшие решения из **Taskwarrior**, **Calcurse** и **Lazygit**.

---

## 🧭 1. Ключевые принципы дизайна (3 Pillars)

1. **⚡ Умная срочность (Taskwarrior):** Динамический расчет коэффициента `Urgency Score`. Задачи с горящими дедлайнами и высоким приоритетом автоматически всплывают наверх.
2. **🗓️ Быстрый недельный обзор (Calcurse):** Мгновенное переключение между днем и недельной сеткой по `w` / `Tab`. Наглядная шкала прогресса и загрузки по дням.
3. **💡 Интуитивные контекстные подсказки (Lazygit):** Нижняя панель подсказок всегда отображает доступные клавиши для активного контекста, а клавиша `?` вызывает полноэкранную шпаргалку.

## ⚡ 3. Формула срочности (Taskwarrior Urgency Algorithm)

Каждой задаче присваивается весовой коэффициент:

$$\text{Urgency} = U_{\text{base}} + U_{\text{due}} + U_{\text{priority}} + U_{\text{tags}} + U_{\text{time}}$$

### Таблица весовых коэффициентов:

| Фактор | Условие / Атрибут | Коэффициент | Индикатор |
| :--- | :--- | :---: | :---: |
| **Просрочено (Overdue)** | `@due( < today )` | **+12.0** | 🔴 Красный |
| **Дедлайн сегодня** | `@due( == today )` | **+10.0** | 🔴 Красный |
| **Дедлайн завтра** | `@due( == tomorrow )` | **+6.0** | 🟠 Оранжевый |
| **Дедлайн на неделе** | `@due( <= today + 7d )` | **+3.0** | 🟡 Жёлтый |
| **Приоритет HIGH** | `@prio(high)` | **+4.0** | 🔴 |
| **Приоритет MEDIUM** | `@prio(med)` | **+2.0** | 🟠 |
| **Приоритет LOW** | `@prio(low)` | **+0.5** | ⚪ |
| **Ближайший тайм-слот** | `@time(HH:MM)` в пределах 1 часа | **+3.5** | ⏰ |
| **Выполненная задача** | `Done == true` | **Фиксировано 0.0** (в конец) | 🟢 |

## ⌨️ 4. Карта горячих клавиш (Keybindings Map)

### Общая навигация (Vim-style):
* `j` / `↓` — Вниз
* `k` / `↑` — Вверх
* `h` / `←` — Предыдущий день / день слева
* `l` / `→` — Следующий день / день справа
* `Tab` — Переключение активной панели (Задачи ↔ Детали ↔ Неделя)
* `w` — Недельный вид (`Week View`)
* `d` — Дневной вид (`Day View`)
* `t` — Переход к сегодняшней дате (`Today`)

### Действия с задачами:
* `Space` — Переключить статус (`Done` / `Not Done`)
* `a` — Быстрое добавление задачи (`Quick Add Input`)
* `e` — Редактировать заголовок
* `d` / `Delete` — Удалить задачу
* `n` — Добавить заметку к выбранной задаче
* `Shift + J` / `Shift + K` — Переместить задачу вверх/вниз в списке
* `s` — Циклическое переключение сортировки: `Urgency` ➔ `Time` ➔ `Custom Order`

### Глобальные команды:
* `/` — Поиск по всему архиву
* `#` — Фильтр по тегу
* `l` — Новая запись в `Daily Log` дня
* `?` — Показать/скрыть модальное окно подсказок (Lazygit-style)
* `q` / `Ctrl+C` — Выход
